# ChronoVault Folder Maker App

## Project Purpose

ChronoVault Folder Maker App is a Visual Basic console application that automatically creates an organized project folder structure. The app helps users quickly set up a project workspace by generating folders for documentation, source code, screenshots, testing, and other project resources.

## Week 8 Update - Version 2.0

Version 2.0 adds **JSON persistence**. The application can now save project information into a JSON file, allowing important data to be stored and accessed after the program closes.

New features added:

* Added the Newtonsoft.Json package.
* Created a Project class to organize project information.
* Added JSON serialization to save project data.
* Added comments to procedures and functions for better code readability.

## How To Understand This Submission

1. Open the Visual Studio project files to view the application's source code.
2. Review the **Docs** folder to see the Week 8 changes, JSON notes, and application documentation.
3. Open **jsonData.json** to view the saved project information created through JSON serialization.
4. Review the **Screenshots** folder to see proof of testing and completed requirements.
