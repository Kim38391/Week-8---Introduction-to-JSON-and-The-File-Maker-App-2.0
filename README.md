# Week-8---Introduction-to-JSON-and-The-File-Maker-App-2.0
Project Purpose:
ChronoVault Folder Maker App is a console application that automatically creates an organized project folder structure. The app helps users quickly set up folders for documentation, source code, screenshots, and testing.
Week 8 Update:
Version 2.0 adds JSON persistence. The application now saves project information into a JSON file so important data can be stored and accessed after the program closes.
Project Contents:
ChronoVaultApp:
Contains the main application files and source code for the ChronoVault project.
Source Code:
Contains the Visual Basic files that control the application's functions, including folder creation and JSON saving.
Project Files:
Contains files required to open and manage the project in Visual Studio.
Docs:
Contains application documentation, change logs, and assignment-related notes.
Screenshots:
Contains screenshots showing the application running, created folders, JSON output, and Discord proof.
Testing:
Contains testing information and project submission materials.
jsonData.json:
Contains saved project information created through JSON serialization.
ReadMe.txt:
This file explains the purpose of the project, folder organization, and how to understand the submission. 

How To Understand This Submission:
1.	Open the Visual Studio project files to view the application's source code.
2.	Review the documentation folder to see the Week 8 changes and JSON notes.
3.	View the JSON file to see the saved project information.
4.	Review screenshots to see proof of testing and completed requirements.
